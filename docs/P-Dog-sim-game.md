# P-Dog Pupperstuf the III - sim game

## Introduction

The main character, P-Dog is conjured into his simulated existence in his simulated environment solely for entertainment and learning purposes of the author.

The code is written in Rust, with generous help from various AI Agents, as is now the norm in the post manual coding singularity, which, sprung on us developer somewhere between January and August 2026.

:headstone: RIP beautifully handcrafted manual coding. It has been a great and enjoyable ride; **exit(0);**

Indeed this artifact is still an exercise in using clever, and not so clever semantic, to define how things interact with each other, what motivates them to take action; spring off the couch and bark to the perceived intruder.

Any similarity to actual persons or creatures, living or dead, is purely coincidental.

## P-Dog Pupperstuf the III

**P-Dog pupperstuf the III**, henceforward **P-Dog**, the main character, is an 11 lbs dog with a short white fur, fluffy ears, fluffy tail, and long legs. Is a mix between a Whippet a Jack Russell Terrier, and, very likely, a Chihuahua due to his feisty, big-dog personality. He has the cutest mug of a baby seal which makes him both more irresistible and dangerous to the unsuspecting passer by.
